# 경매 검색조건 매핑

진단 결과를 **법원경매(courtauction.go.kr)에서 바로 거를 수 있는 필터**로 변환한다.
핵심은 결정적 함수: `검색조건 = f(유형 축, 사실 입력)`. 같은 입력이면 항상 같은 결과.

## 1. 사실이 뼈대, 성향이 취향

| 갈래 | 값 | 결정하는 것 |
|---|---|---|
| **사실** | 예산 · 지역 · 주택 보유 수 · 경험 | 가격 상·하한, 지역, 안전장치 |
| **성향** | 권리(S/R) · 손품(E/H) · 출구(K/P) | 특수조건, 유찰 횟수, 물건 종류, 면적 |

성향이 예산을 이기지 못한다. 예산 5천만 원이면 "대범한 성향"이어도 아파트는 검색에서 빠진다.

## 2. 가격 상한 (핵심)

```
가격 상한 = 예산 × 대출배수 × 예비비계수
```

**대출배수** — 반드시 `_workspace/00_regulations.md` 근거:

| 지역 | 무주택 | 1주택 | 다주택 |
|---|---|---|---|
| 비규제 | 3.3 (LTV 70%) | 3.3 | 2.31 (3.3×0.7, 한도·DSR 제약) |
| 규제 | 1.7 (LTV 40%, 생애최초 3.3) | 1.0 (주담대 금지) | 1.0 (주담대 금지) |
| 판정 불가 | 규제 기준으로 보수적 계산 | | |

**예비비계수** — 성향 계수이며 **규제 수치가 아니라고 반드시 명시**한다:
- 손품 직접형 `H` ×0.85 (수리·이사비)
- 권리 모험형 `R` ×0.9 (소송·장기화)
- 둘 다면 곱해서 ×0.765

**경락잔금대출도 대출규제가 동일 적용된다**(00_reg D절). "경매라서 예외"라고 쓰지 않는다.

> ⚠️ 출력에 항상 함께 낸다: **"가격 상한은 검색 범위일 뿐 입찰가 상한이 아니다."** 입찰가는 시세 역산으로 따로 정한다. 특히 규제지역은 토지거래허가·2년 실거주 의무가 경매에 면제되어 수요가 몰리고 고가 낙찰이 잦다.

## 3. 나머지 차원

| 차원 | 규칙 |
|---|---|
| **유찰 횟수** | 기본 1 → `R` +1 → `P` +1 → 규제지역 +1 → (`S`+`E`이고 예산 1.5억 초과) −1, 최소 0. 0이면 "제한 없음"으로 표기 |
| **특수조건** | `S` 미체크 / `R` 체크(유치권·법정지상권·분묘기지권·지분·대지권미등기·선순위 임차인) |
| **물건 종류** | `K` 오피스텔·다세대/연립·아파트(소형) / `P` 아파트·다세대/연립. 예산 5천 이하 → 아파트 제외, 3억 초과 → 다세대/연립 제외 |
| **면적** | `K` 또는 예산 5천 이하 → 전용 59㎡ 이하 / `P` → 59~84㎡ |
| **지역** | 입력 그대로. 시/도+시군구로 **규제 여부 자동 판정**(00_reg §E 목록) |

## 4. 초보 안전장치

경험 = 초보이고 권리 = `R`이면:
- **유형 코드는 유지**한다(성향은 성향이다).
- **검색조건만** `safe`로 하향하고, `danger` 배너로 "왜 낮췄는지"를 밝힌다.

결과를 몰래 바꾸면 사용자는 이유를 알 수 없다. 성향과 실행 권고는 분리해 둘 다 보여준다.

## 5. 사이트로 못 거르는 것은 메모로

| 필터 O | 메모(플래그) |
|---|---|
| 지역 · 물건종류 · 최저매각가격 · 유찰횟수 · 특수조건 · 면적 | 규제 여부 · 대출 가용액/DSR · 취득세/양도세 · 명도 난이도 · 수리 상태 |

규제 수치는 `00_regulations.md`만 근거로 하고, `[불확실]` 항목은 "확인 필요"로 쓴다. 면책을 항상 유지한다.

## 6. 출력

- `_workspace/04_search_criteria.md` — 규칙 설명(사람이 읽는)
- `_workspace/04_search_criteria.json` — 계산 규칙 + **골든 케이스 4건**

**골든 케이스는 규칙마다 다른 분기를 밟게 설계한다:**

| ID | 무엇을 검증하나 |
|---|---|
| G1 | 기본 — 비규제·무주택·계수 1개 |
| G2 | 규제지역 — 대출배수 하락 + 유찰 +1 |
| G3 | 다주택 + 계수 중첩(H·R 동시) |
| G4 | 초보 안전장치 + 전 계수 중첩(최소 상한) |

각 케이스에 `calc` 문자열로 계산 과정을 남긴다. QA는 브라우저에서 실제 함수를 실행해 **원 단위까지** 대조한다.

## 7. 검증

1. 검색조건이 유형·입력과 모순 없는가(모험형인데 미체크? → 초보 하향일 때만 허용).
2. 모든 필드를 사이트에서 거를 수 있는가(아니면 메모로).
3. 규제 수치가 `00_regulations.md`에만 근거하는가.
4. 예산 5천 + 아파트 조합이 나오지 않는가.
5. 계산식을 바꿨으면 **골든 케이스 기대값도 함께 갱신**했는가.
