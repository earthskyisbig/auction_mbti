# 후보 축 (출발점 — 비판적으로 검토·수정할 것)

이 목록은 시작점일 뿐이다. SKILL.md의 §0(성향인가 사실인가)과 §1(좋은 축의 조건)으로 각 후보를 검증하고, 걸러지는 것은 버리거나 합쳐라. **그대로 베끼지 말 것.**

## 1. 채택된 축 (v2 정본, 3축)

| 축 | 극 A | 극 B | trade-off | 결정하는 검색조건 |
|---|---|---|---|---|
| **권리 리스크** | 안전형 `S` — 권리 단순한 물건만 | 모험형 `R` — 인수 위험 있어도 싸면 | 안전=실수↓·경쟁↑(비싸게) / 모험=싸게·분석 실패 시 큰 손실 | 특수조건 체크, 유찰 +1, 예비비 ×0.9 |
| **손품** | 간편형 `E` — 손 안 대는 물건 | 직접형 `H` — 명도·수리 직접 | 간편=시간·스트레스↓·프리미엄 지불 / 직접=고생을 마진으로, 기간·비용 초과 위험 | 물건 상태 메모, 유찰, 예비비 ×0.85 |
| **출구** | 월세형 `K` — 보유·임대 | 차익형 `P` — 정리 후 매각 | 월세=현금흐름·자본 묶임 / 차익=회전·단기 양도세 | 물건 종류, 면적, 유찰 +1 |

## 2. 탈락한 후보와 그 이유

| 후보 축 | 판정 | 이유 |
|---|---|---|
| 자금: 소액분산 ↔ 대액집중 | **탈락 → 사실 입력** | 예산은 취향이 아니라 현실. 축에 넣으면 "대범해서 대액형"이라는 모순이 생긴다 |
| 지역: 연고지 ↔ 전국 | **탈락 → 사실 입력** | 임장 가능 범위는 조건이지 성향이 아니다. "전국"이라 답해도 실제 이동 범위는 정해져 있다 |
| 보유기간: 단기 ↔ 장기 | **흡수 → 출구 축** | 월세/차익과 거의 완전히 상관. 따로 물으면 문항만 는다 |
| 명도 가능 여부 | **흡수 → 손품 축** | 수리·추가비용과 같은 것을 묻는다("낙찰 후 몸과 돈을 더 쓸 각오") |
| 수리 가능 여부 | **흡수 → 손품 축** | 위와 동일 |
| 추가비용 허용 여부 | **흡수 → 손품 축** | 위와 동일 |
| 유찰 횟수 선호 | **탈락 → 파생값** | 초보가 답할 수 없다("몇 번이 좋은 건가요?"). 다른 축에서 자동 계산된다 |
| 물건 종류 선호 | **탈락 → 파생값** | 선택이 아니라 결과. 예산 5천에 아파트를 고르면 검색 결과가 0건이다 |
| 투자 목적(실거주/임대/매각) | **분할** | 실거주 여부 = 사실(주택 보유 수) / 임대 vs 매각 = 출구 축 |
| 경매 경험 | **탈락 → 안전장치** | 경험은 성향이 아니다. 점수에 넣으면 초보는 영원히 안전형이 되고, 경험이 쌓여도 결과가 안 바뀐다 |
| 권리분석 자신감 | **탈락** | 자기 평가라 신뢰도가 낮고, 권리 축과 중복된다 |

## 3. 다음에 축을 추가하고 싶을 때

새 축을 넣기 전에 세 가지를 통과시켜라:

1. **성향인가?** 같은 조건의 두 사람이 다르게 답하고 둘 다 합리적인가.
2. **독립적인가?** 기존 3축 중 어느 것과도 강하게 상관되지 않는가.
3. **검색조건을 바꾸는가?** 그 축의 극이 다르면 실제로 다른 필터가 나오는가. **이걸 못 쓰면 축이 아니다.**

셋을 통과해도, 축을 늘리면 유형이 2배가 된다(3축 8 → 4축 16). 콘텐츠·검증 부담이 2배가 되고 모순 조합이 생기기 쉽다. **정말 필요한지 한 번 더 묻는다.**

검토해 볼 만한 후보: 경쟁 회피(남들이 몰리는 물건 ↔ 아무도 안 보는 물건 — 단 권리 축과 상관이 높다), 속도(빨리 여러 건 ↔ 신중히 한 건 — 예산과 상관될 수 있다).
