Mono Signal

설치
알아둘 것
data-theme이 없으면 다크로 동작합니다. 모든 클래스에 ms- 접두어가 붙어 기존 스타일과 부딪히지 않습니다. 토큰만 가져다 쓰고 컴포넌트는 직접 짜도 됩니다.
색

액센트는 하나입니다. 시안과 살몬은 의미가 사라지면 안 되는 곳(정보 구분·경고)에만 씁니다. 라이트 모드에 라임을 남기지 마세요 — 밝은 배경 위에서 대비가 무너집니다.

서체

Pretendard 하나로 제목·본문·라벨을 모두 처리합니다. 서체를 늘리는 대신 굵기 대비(800 ↔ 450)와 자간으로 위계를 만듭니다.

쓸 때 지킬 것
  1. 액센트는 하나. 라임을 여기저기 쓰면 강조가 사라집니다. 한 화면에서 라임이 붙는 곳은 서너 군데면 충분합니다.
  2. 라이트 모드에 라임을 남기지 마세요. 밝은 배경 위 라임은 대비가 무너집니다. 액센트를 근-검정으로 바꿉니다.
  3. 데이터 앞에 안내 한 줄. .ms-readme로 "이건 무엇을 보는 것인가"를 먼저 말합니다.
  4. 내부 자료구조는 접습니다. 배열·키 이름을 그대로 노출하지 말고 .ms-adv 안으로 넣은 뒤, 바깥에는 그게 무슨 일을 하는지 문장으로 씁니다.
  5. 이분법 대신 스펙트럼. 값이 연속적이면 라벨 하나로 찍지 말고 위치로 보여주고, 애매하면 애매하다고 표시합니다.
  6. 단계가 있으면 지도를 반복합니다. 화면마다 .ms-flow를 같은 자리에 둡니다.
  7. 사용자 문구에 개발 용어를 쓰지 않습니다. 스키마명·API명 대신 무엇을 어디에 넣는지로 씁니다.
  8. 서체를 늘리지 않습니다. Pretendard 하나로 굵기와 자간만으로 위계를 만듭니다.
