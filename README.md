# 법원경매 투자성향 테스트

질문 9개로 **법원경매 투자성향 8유형** 중 하나를 진단하고, 법원경매정보 사이트에 그대로 넣을 **검색조건**(지역·물건종류·가격 상한·특수조건·면적)을 계산해 줍니다. **본인 투자 판단용** 도구입니다.

> 💻 **로컬 실행**: `index.html`을 브라우저로 열면 됩니다. 설치 불필요, 단일 파일, 수집 없음.
> 🔗 온라인(main 브랜치 배포본): https://earthskyisbig.github.io/auction_mbti/

## 무엇이 다른가

일반적인 성격 테스트가 아닙니다. **경매 물건을 검색할 때 실제로 입력하는 조건**을 성향과 사실로 나눠, 성향은 질문으로 재고 사실은 그대로 받아 **검색조건을 계산**합니다.

| | 무엇 | 어떻게 쓰나 |
|---|---|---|
| **성향** (질문 9개) | 권리 위험 허용 · 명도/수리 감내도 · 월세 vs 차익 | 예비비 계수, 유찰 참고값, 함정·체크리스트 |
| **사실** (직접 입력) | 취득 주체 · 자금 · 지역(복수) · 보유 수 · 경험 · 물건 종류(복수) · 면적 · 특수물건 희망 | 가격 상·하한, 검색 지역·종류·면적, 규제·세금 경고 |

자금·지역은 취향이 아니라 현실이므로 **성향 점수에 넣지 않습니다.**

### 사실을 정확히 받는 장치

- **지역은 여러 곳** 고를 수 있습니다. 시·군·구 하나씩은 물론 **시·도 전체 / 수도권 전체 / 전국**도 담을 수 있고, 규제지역인지는 자동으로 판정해 표시합니다.
- **동원 가능 총액**(대출 포함)을 적으면 대출 한도 추정을 쓰지 않고 **그 금액을 그대로** 검색 상한으로 씁니다.
- **취득 주체**(개인 / 매매사업자 / 법인)에 따라 대출 가능 여부와 세금 계산법이 완전히 달라집니다. 매매사업자·법인은 주택구입 목적 주담대를 받을 수 없고, 취득세는 개인 3주택과 같습니다.
- **면적은 종류별로 따로** 묻습니다. 아파트 59㎡·빌라 59㎡·오피스텔 59㎡는 체감 크기가 전혀 다릅니다. 모든 기준은 공급면적이 아닌 **전용면적**입니다.
- **특수조건 10종**(법정지상권·별도등기·유치권·분묘기지권·특별매각조건·농지취득자격·선순위·예고등기·우선매수신고·재매각)을 **설명과 함께** 제시하고 본인이 고릅니다. 성향이 모험형이어도 자동으로 켜지 않습니다.

### 유찰 횟수를 필터에 넣지 않는 이유

유찰 1회당 최저가는 20~30% 내려갑니다. 즉 **유찰 횟수와 가격 조건은 사실상 같은 정보**라 둘 다로 좁히면 볼 물건이 사라집니다. 대신 결과 화면에서 **읽는 법**을 알려줍니다 — 아파트는 3회 초과가 드물고, 많이 유찰됐다면 가격이 아니라 권리·물건 하자를 의심해야 하며, HUG 대위변제 포기 물건은 유찰이 누적되는 경향이 있습니다.

### 경매만 되는 것 (결과에 항상 표시)

| | 일반 매매 | 경매 |
|---|---|---|
| 토지거래허가 | 필요 | **불요** |
| 토허 2년 실거주 의무 | 부과 | **면제** |
| 투기과열지구 조합원 지위 | 재건축 조합설립 후·재개발 관리처분 후 **양도 제한** | ⚠️ **예외 여부 확인 필요** (아래 참조) |

앞의 두 가지는 확실합니다. **세 번째는 단정하지 않습니다** — 자세한 이유는 아래 "확인이 끝나지 않은 항목"에 있습니다. 대신 확실한 사실을 안내합니다: **재개발은 관리처분인가 전까지 자유롭게 양도**되므로 그 전 단계 물건은 경매든 일반매매든 문제가 없습니다.

## 3개 축 · 8개 유형

| 축 | 두 극 |
|---|---|
| 권리 | 안전형 `S` ↔ 모험형 `R` |
| 손품 | 간편형 `E` ↔ 직접형 `H` |
| 출구 | 월세형 `K` ↔ 차익형 `P` |

| 코드 | 유형 | 한 줄 |
|---|---|---|
| `A-SEK` | 속 편한 월세 대장 | 깨끗한 물건 받아 손 안 대고 세 놓는다 |
| `A-SEP` | 손 안 대는 차익러 | 깨끗한 물건 싸게 받아 그대로 되판다 |
| `A-SHK` | 셀프 수리 임대인 | 안전한 낡은 집을 고쳐 월세를 올린다 |
| `A-SHP` | 고쳐 파는 실속러 | 안전한 낡은 집을 고쳐 값 올려 판다 (입문 권장) |
| `A-REK` | 서류 파고드는 임대인 | 권리는 복잡해도 사람 상대는 피한다 |
| `A-REP` | 권리 틈새 차익러 | 무서운 물건을 싸게 받아 정리 후 판다 |
| `A-RHK` | 맨손 개척 임대인 | 권리도 명도도 직접, 오래 보유 |
| `A-RHP` | 경매 풀코스 플레이어 | 전부 직접 하고 되판다 (최고 난도) |

## 계산 방식

```
동원 총액을 입력한 경우:   가격 상한 = 입력한 총액 × 예비비계수
입력하지 않은 경우:        가격 상한 = 내 돈 × 대출배수(추정) × 예비비계수
```

**대출배수** — 위에서부터 먼저 걸리는 규칙을 씁니다.

| 조건 | 배수 |
|---|---|
| **매매사업자·법인** (지역 무관) | **1.0** — 주택구입 목적 주담대 불가 |
| **1주택·다주택** (개인) | **1.0** — 원칙 LTV 0%. 6개월 내 처분조건부면 아래 적용 |
| 규제지역 + 무주택 | 1.67 (LTV 40%. 생애최초면 3.33) |
| 비규제 + 무주택 | 3.33 (LTV 70%) |

여기에 **절대 캡**(주택가격 15억 이하 6억 / 15~25억 4억 / 25억 초과 2억)이 한 번 더 걸립니다. DSR(1금융 40% / 2금융 50%)은 소득을 받지 않아 계산에 넣지 않고 안내만 합니다.

**예비비계수**: 직접형 ×0.85 · 특수물건 선택 ×0.9 · 성향만 모험형 ×0.95
지역을 여러 곳 골랐다면 **한 곳이라도 규제지역이면 규제 기준**으로 보수적으로 계산합니다.

- **규제지역은 묻지 않고** 지역 입력에서 자동 판정합니다(2025-10-15 서울 전역 + 경기 12곳, 2026-06-30 구리·화성 동탄구·용인 기흥구 추가).
- **초보 경고**: 경험 없음 + 특수물건 선택이면 위험 배너를 띄우되, **선택 자체는 되돌리지 않습니다.**
- 대출·세금 수치는 2025 6·27 / 9·7 / 10·15 대책과 2026-06-30 추가지정을 근거로 합니다.

> ⚠️ 가격 상한은 **검색 범위**일 뿐 **입찰가 상한이 아닙니다.** 입찰가는 시세에서 역산해 따로 정하세요.

## 2026년 세제개편안 반영 (원문 확정)

「2026년 세제개편안 상세본」 pp.56–96을 직접 판독해 결과 화면에 수치를 반영했습니다. **단 국회 통과 전 「안」이므로 시행 시 최종 조문을 확인해야 합니다.**

| 항목 | 내용 |
|---|---|
| 종부세 공정시장가액비율 | 60% → **70%**(’27). **3주택 이상 또는 조정대상지역 주택 보유자**는 ’28년 **80%** |
| 종부세 세율 | ’28년부터 **주택 수 차등 폐지 → 가액 단일세율**(0.5~5.0%) |
| 세부담 상한 | 150% → **200%** |
| 1세대1주택 세액공제 | 보유기간 → **거주기간** 공제로 전환, 금액한도 신설(800만 → 600만) |
| 양도세 중과(2년↑ 보유) | 2주택 +20%p → **’27년 +5%p** → ’28년 +10%p / 3주택↑ +30%p → **’27년 +10%p** → ’28년 +15%p |

개정이유 원문이 **"다주택자 보유세 정상화에 따른 매도 기회 부여"**입니다. **’27년이 완화 폭이 가장 큰 구간**이며, ’26년 양도분도 ’27.1.1. 이후 신고하면 완화세율을 받습니다. 다만 **보유 2년 미만 단기 매각에는 적용되지 않습니다.**

## ⚠️ 확인이 끝나지 않은 항목

- **조합원 지위 승계의 경·공매 예외** — 실무에서 널리 알려진 내용이지만 **도시정비법 §39②·시행령 §37②의 예외 목록에서 확인하지 못했습니다.** 앱은 단정하지 않고 "입찰 전 조합·법무사 확인"으로 안내합니다. 확실한 것은 **재개발이 관리처분인가 전까지 자유롭게 양도된다**는 점입니다.
- **공시가격 저가주택 취득세 중과 제외** — 기준 금액을 단정하지 않고 "공시가격을 확인하라"는 안내로만 제공합니다.
- **대출 매트릭스** — 강의자료 기반이며 감독규정 원문 대조는 미완입니다. 은행별 취급 차이가 큽니다.

## 결과를 파일로 남기기

결과 화면의 **💾 결과 저장 (JSON)** 버튼은 입력한 조건·9문항 답변·유형·계산된 검색조건을 한 파일에 담습니다.

```bash
python save_server.py            # http://127.0.0.1:8899/index.html
```

이 서버를 켜고 접속해서 테스트하면 **`responses/` 폴더에 바로 저장**됩니다(`responses/README.md` 참조).
서버 없이 파일을 그냥 열면 저장 위치를 고르는 창이 뜨거나 다운로드 폴더로 떨어집니다.

## 프로젝트 구조

```

  01_typology.md             축·유형 정본
  02_diagnostic.json         문항·사실입력·유형·플래그 (웹의 데이터 원본)
  02_scoring.md              채점 규칙
  03_profiles.md             유형 콘텐츠 원칙
```

## ⚠️ 면책

- 본 테스트는 **투자 참고용**이며 세무·법률·투자 자문이 아닙니다.
- 부동산 규제·세율은 수시로 변경됩니다. 일부 항목(양도세 중과 유예 종료 등)은 "확인 필요"로 표기돼 있습니다.
- **실제 입찰·대출·세금 적용 전 반드시 금융기관·세무사·법무사 등 전문가와 해당 시점 규정을 직접 확인**하세요.
