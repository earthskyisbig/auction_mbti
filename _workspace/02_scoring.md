# 02. 채점 규칙 (v2)

> 데이터 정본은 `02_diagnostic.json`. 이 문서는 그 규칙을 사람이 읽는 설명이다.

## 1. 구조

- 축 3개 × 문항 3개 = **성향 문항 9개**
- 그 외 **사실 입력 4개**(예산·지역·주택 보유 수·경매 경험) — 점수에 넣지 않는다.

## 2. 점수 계산

각 문항의 선택지는 그 축의 한쪽 극에 **1점**을 준다.

```
RIGHTS: q1, q2, q3  → S 또는 R
WORK  : q4, q5, q6  → E 또는 H
EXIT  : q7, q8, q9  → K 또는 P

유형코드 = "A-" + (S|R) + (E|H) + (K|P)
```

축마다 3문항이므로 결과는 **3:0 또는 2:1**이며 **동점이 나오지 않는다.**
(축당 2문항이면 1:1 동점 처리 로직이 필요해진다 — 3문항으로 잡은 이유.)

## 3. 기울기 표시

| 점수 | 표기 | 결과 화면 문구 |
|---|---|---|
| 3:0 | 뚜렷함 | (별도 문구 없음) |
| 2:1 | 약간 기울어짐 | "이 축은 상황에 따라 바뀔 수 있습니다" |

2:1인 축은 결과 화면의 축 카드에 회색 표시를 하고, 반대쪽 유형도 "함께 볼 만한 유형"으로 링크한다.

## 4. 계산 예시

답: q1-B(R), q2-A(S), q3-B(R) / q4-B(H), q5-B(H), q6-B(H) / q7-B(P), q8-B(P), q9-A(K)

| 축 | 점수 | 결과 | 기울기 |
|---|---|---|---|
| RIGHTS | S 1 : R 2 | **R** | 약간 기울어짐 |
| WORK | E 0 : H 3 | **H** | 뚜렷함 |
| EXIT | K 1 : P 2 | **P** | 약간 기울어짐 |

→ **A-RHP** (경매 풀코스 플레이어)

## 5. 점수에 넣지 않는 것 (중요)

- **경매 경험**: 유형 점수에 절대 반영하지 않는다. 검색조건 하향(초보 안전장치)과 경고 강도에만 쓴다.
  - 이유: 경험은 성향이 아니다. 초보라는 이유로 "안전형"으로 판정하면 본인 성향을 알 수 없게 되고, 경험이 쌓여도 결과가 안 바뀐다.
- **예산·지역·주택 보유 수**: 검색조건 계산에만 쓴다(`04_search_criteria.json`).

## 6. 저장·공유 (미구현 — 향후)

현재 웹은 **검색조건 복사·인쇄**만 제공한다. 링크 공유를 넣는다면 결과 URL을 `#A-RHP.u50.none.novice.<지역코드>` 형식으로 인코딩한다.
**v1 코드(`A-scnr` 등)는 v2에서 인식하지 않는다** — v1 링크가 들어오면 시작 화면으로 보낸다.
