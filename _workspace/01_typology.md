# 01. 경매 투자성향 유형 체계 (v2 — 3축 8유형 확정본)

> **범위**: 법원경매 **단독 트랙**. 매매 트랙은 v2에서 폐기.
> **설계 원칙**: 사용자가 검색창에 넣는 조건 중 **"사람마다 갈리는 것"만 성향 축**으로 삼고, **"현실로 정해진 것"(예산·지역·보유수·경험)은 사실 입력**으로 분리한다.
> 이 문서의 축 코드·유형 코드는 **다운스트림(문항·프로필·검색조건·웹)의 고정 계약**이다.

---

## 0. v1(4축 16유형) → v2(3축 8유형) 변경 근거

| v1 축 | v2 처리 | 이유 |
|---|---|---|
| ① 자금 (소액분산/대액집중) | **축에서 제거 → 사실 입력(예산)** | 성향이 아니라 현실. "나는 대범하다"고 답해도 5천만 원으로 10억을 살 수 없다. 성향 점수에 넣으면 예산 없는 사람이 대액형으로 판정되는 모순이 생긴다. |
| ③ 지역 (연고/전국) | **축에서 제거 → 사실 입력(지역)** | 사는 곳·임장 가능 범위는 취향이 아니라 조건. |
| ② 난이도 (안전/특수) | **유지 → ① 권리 축** | 진짜로 사람마다 갈린다. 양쪽 다 합리적. |
| ④ 용도 (보유/매각) | **유지 → ③ 출구 축** | 유지. 단 "보유기간"과 "월세/차익"은 같은 축이므로 합쳐서 측정. |
| — | **신설 → ② 손품 축** | 명도·수리·추가비용 감내도. v1에 없던 축이며, 실제 초보자의 물건 선택을 가장 크게 가르는 변수. |

**명도·수리·추가비용을 한 축으로 묶은 이유**: 세 조건 모두 "낙찰 후에 몸과 돈을 더 쓸 각오"를 묻는다. 실제로 이 셋에 서로 다르게 답하는 사람은 드물고(수리는 되는데 명도는 못 하겠다 → 결국 "손 안 대는 물건"만 찾게 됨), 나누면 문항만 늘고 유형은 의미 있게 늘지 않는다.

**16 → 8로 줄인 이유**: v1은 16유형 중 6개에 스스로 "희귀/모순" 주석이 달려 있었다(`A-sxwr`, `A-sxwf` 등). 자금·지역을 축에서 빼면 조합 모순이 사라져 **8개 전부가 현실에 존재하는 유형**이 된다.

## 1. 축 (순서 고정: ① 권리 → ② 손품 → ③ 출구)

### ① 권리 리스크 — 안전형 `S`(Safe) ↔ 모험형 `R`(Risk-taker)
- **정의**: 등기부·임차인 관계가 단순한 물건만 다루는가, 인수 위험이 있는 물건에도 들어가는가.
- **극 의미**: `S` = 말소기준권리 이하 전부 소멸, 인수할 권리 0, 인도명령 가능 / `R` = 유치권·법정지상권·지분매각·대지권미등기·선순위 임차인 등 쟁점 물건 허용.
- **trade-off**: 안전 = 실수 확률 낮음, 경쟁이 몰려 낙찰가율 높음(비싸게 산다) / 모험 = 경쟁 적어 싸게 낙찰, 권리분석 실패 시 손실·자금 장기 고착.
- **측정**: 같은 값 두 물건 중 선택 / 인수 부담 3천만 원 제시 상황 / 남들이 피하는 물건에 대한 해석.
- **결정하는 검색조건**: 특수조건 체크 여부, 유찰 횟수(+1), 예비비 계수(×0.9).

### ② 손품(실행) — 간편형 `E`(Easy) ↔ 직접형 `H`(Hands-on)
- **정의**: 낙찰 후 명도·수리·예상 외 비용을 감수하는가, 손대지 않아도 되는 물건을 선호하는가.
- **극 의미**: `E` = 비어 있거나 인도명령으로 정리되는 물건, 바로 쓸 수 있는 상태 선호 / `H` = 점유자 협의·강제집행, 도배·장판·설비 교체, 밀린 관리비까지 계산에 넣고 진입.
- **trade-off**: 간편 = 시간·스트레스 적음, 그만큼 낙찰가에 프리미엄 / 직접 = 고생을 마진으로 바꿈, 기간 지연·초과비용 위험.
- **측정**: 점유자 대면 / 전면 수리 필요 / 예상 못 한 지출(관리비·이사비).
- **결정하는 검색조건**: 물건 상태 선호(메모), 유찰 횟수, 예비비 계수(×0.85).
- **주의**: 이 축은 "능력"이 아니라 **감내도**다. 결과 문구에서 `E`를 열등하게 서술하지 않는다.

### ③ 출구 — 월세형 `K`(Keep) ↔ 차익형 `P`(Profit)
- **정의**: 보유하며 임대수익을 받는가, 정리 후 매각해 차익을 실현하는가.
- **극 의미**: `K` = 장기 보유, 매달 현금흐름 / `P` = 명도·수리 후 매각, 자본 회전.
- **trade-off**: 월세 = 안정적 현금흐름, 자본 묶임·관리 부담 / 차익 = 회전 빠름, 단기 양도세·매도 지연 위험.
- **측정**: 월 40만 원 vs 2년 뒤 2천만 원 / 목표 보유기간 / 현금흐름 vs 자산 증식.
- **결정하는 검색조건**: 물건 종류, 전용면적, 유찰 횟수(+1).
- **비고**: v1의 "실거주"는 축에서 제외하고 사실 입력(주택 보유 상황)으로 처리한다. 실거주 목적은 `K`(보유)의 하위 상황으로 해석한다.

## 2. 유형 매트릭스 (8, 축순서 S/R - E/H - K/P)

| 코드 | 유형명 | 한 줄 | 잘 맞는 물건 | 가장 큰 함정 |
|---|---|---|---|---|
| `A-SEK` | 속 편한 월세 대장 | 깨끗한 물건 받아 손 안 대고 바로 세 놓는다 | 공실 오피스텔·소형 아파트, 권리 단순 | 경쟁이 몰려 비싸게 낙찰 → 수익률이 예금 수준으로 깎임 |
| `A-SEP` | 손 안 대는 차익러 | 깨끗한 물건 싸게 받아 그대로 되판다 | 유찰 2회↑ 국민평형 아파트 | 손을 안 대면 파는 값도 안 오른다. **낙찰가 자체가 싸야만** 성립 |
| `A-SHK` | 셀프 수리 임대인 | 안전한 낡은 집을 고쳐 월세를 올린다 | 구축 다세대·소형 아파트 | 수리비를 월세로 회수하는 기간(보통 3~5년) 계산 누락 |
| `A-SHP` | 고쳐 파는 실속러 | 안전한 낡은 집을 고쳐 값 올려 판다 | 구축 국민평형, 명도 쉬운 물건 | 수리비 초과·매도 지연. **초보 권장 코스** |
| `A-REK` | 서류 파고드는 임대인 | 권리는 복잡해도 사람 상대는 피하며 임대 | 선순위 임차인·대지권 미등기 등 서류형 쟁점 | "서류만 복잡한 물건"은 드물다 — 결국 명도가 따라온다 |
| `A-REP` | 권리 틈새 차익러 | 남들이 무서워하는 물건을 싸게 받아 정리 후 판다 | 지분·유치권 주장 물건(유찰 3회↑) | 정리 기간이 예상의 2~3배 → 자금 장기 고착 |
| `A-RHK` | 맨손 개척 임대인 | 권리도 명도도 직접 하고 오래 보유한다 | 저가 다세대·연립, 점유자 있는 물건 | 물건 수가 늘수록 관리가 본업이 된다 |
| `A-RHP` | 경매 풀코스 플레이어 | 권리·명도·수리 다 하고 되판다 | 특수물건 전반 | 수익 최대·난이도 최고. **초보가 여기 나오면 강한 경고 필수** |

**모순 조합 없음.** 8개 모두 현실에 존재하며, 각각 다른 검색조건을 만든다(§4 확인).

## 3. 코드 규칙 (고정 계약)

- **접두**: `A-` (경매)
- **축 순서(고정)**: 권리 → 손품 → 출구
- **극 코드**: 대문자 1자 × 3

| 축 | 극A | 극B |
|---|---|---|
| ① 권리 | 안전형 `S` | 모험형 `R` |
| ② 손품 | 간편형 `E` | 직접형 `H` |
| ③ 출구 | 월세형 `K` | 차익형 `P` |

- 예: `A-SHP` = 안전 · 직접 · 차익.
- **v1 코드(`A-scnr` 등)와 호환되지 않는다.** 저장된 v1 결과 링크는 v2에서 무효 처리한다.

---

## 4. 사실 입력 (축 아님 — 검색조건의 뼈대)

| 입력 | 값 | 쓰이는 곳 |
|---|---|---|
| **예산** | `u50`(5천 이하) / `u150`(~1.5억) / `u300`(~3억) / `o300`(3억 초과) | 가격 상·하한, 물건 종류, 면적 |
| **지역** | 시/도 + 시군구 | 검색 지역, **규제지역 자동 판정** |
| **주택 보유 수** | `none` 무주택 / `one` 1주택 / `multi` 다주택 | 대출배수(가격 상한), 취득세·양도세 경고 |
| **경매 경험** | `novice` 초보 / `inter` 중급 / `expert` 숙련 | 초보 안전장치(검색조건 하향), 경고 강도 |

**규제지역**은 지역 입력에서 자동 판정한다(00_regulations.md §E 목록). 판정 불가 시 `unknown` → 보수적으로 계산하고 확인 안내를 띄운다. 사용자에게 직접 묻지 않는다(초보는 답할 수 없는 질문).

---

## 5. 초보 안전장치 (설계 결정)

경험 = `novice`이고 권리 축 = `R`인 경우:
- **유형 코드는 그대로 유지한다** (`A-RHP`는 `A-RHP`로 표시). 성향은 성향이다.
- **검색조건만 안전형으로 하향**한다: 특수조건 체크 해제, 유찰 기준은 유지.
- 결과 최상단에 `danger` 배너: *"성향은 모험형이지만, 처음 3건은 권리 단순한 물건으로 시작하세요. 아래 검색조건은 안전형 기준으로 조정했습니다."*

이유: 결과 자체를 바꾸면 "내 성향"이 아니게 되고, 사용자는 왜 바뀌었는지 알 수 없다. 성향과 실행 권고를 분리해 둘 다 보여준다.
