# 04. 진단 결과 → 법원경매 검색조건 (v3)

> **기계용 정본은 `04_search_criteria.json`**. 이 문서는 그 규칙의 설명이다.
> 규제 수치는 `00_regulations.md`(2026-07-01 기준 + 2026-08-03 보강)에서만 인용한다.
> ⚠️ 투자·세무·법률 자문이 아니다. 입찰·대출·세금 적용 전 전문가와 해당 시점 규정을 확인할 것.

---

## 0. 원칙 — 사실이 뼈대, 성향이 취향

| 갈래 | 값 | 결정하는 검색 차원 |
|---|---|---|
| **사실** | 취득 주체 · 자금 · 지역(복수·전체) · 보유수 · 경험 · 물건종류(복수) · 면적 · 특수조건(10종 중 선택) | 지역, 가격대, 물건종류, 면적, 특수조건 |
| **성향** (3축) | 권리(S/R) · 손품(E/H) · 출구(K/P) | 예비비 계수, 유찰 참고값, 결과 콘텐츠 |

**v3에서 성향의 역할이 줄었다.** 물건 종류·면적·특수조건을 사용자가 직접 고르게 했기 때문이다. 성향은 이제 예비비 계수와 "무엇을 조심해야 하는지"를 결정한다.

---

## 1. 가격 상한 — 두 갈래

### (a) 동원 가능 총액을 입력한 경우 → **그 금액이 기준**

```
가격 상한 = 입력한 총액 × 예비비계수
```

대출배수 추정을 쓰지 않는다. 본인이 아는 금액이 추정보다 정확하다.

### (b) 입력하지 않은 경우 → 내 돈 × 대출배수(추정)

```
가격 상한 = 내 돈 상단 × 대출배수 × 예비비계수
```

**대출배수** (00_reg A·B·C·H-3 근거)

| 조건 | 배수 | 근거 |
|---|---|---|
| **수도권 + 매매사업자·법인** | **1.0** | 사업자·법인 주택 대출 사실상 불가 → 자기자본만 |
| 규제지역 · 무주택 | 1.7 | LTV 40% (생애최초면 70% → 3.3) |
| 규제지역 · 1주택·다주택 | 1.0 | 추가구입 주담대 금지 |
| 비규제 · 다주택 | 2.31 | 3.3 × 0.7 (한도·DSR 제약) |
| 비규제 · 무주택·1주택 | 3.3 | LTV 70% |
| 규제 여부 미확인 | 1.7 상한 | 보수적으로 |

한 곳이라도 규제지역이면 **규제 기준으로 계산**한다(보수적). 지역 선택 단위는 §1-1 참조.

**예비비계수** (성향 계수 — 규제 수치 아님)

| 조건 | 계수 | 이유 |
|---|---|---|
| 손품 직접형 `H` | ×0.85 | 수리·이사비 |
| **특수물건 선택함** | ×0.9 | 소송·정리 비용, 기간 장기화 |
| 특수물건 미선택 + 모험 성향 `R` | ×0.95 | 성향만 모험이면 완만하게 |

> ⚠️ 출력에 항상 함께 낸다: **"가격 상한은 검색 범위일 뿐 입찰가 상한이 아니다."**

**하한**: 내 돈이 5천 이하 구간이고 총액 미입력이면 3,000만 원(그 아래는 환금성 문제).

## 1-1. 지역 선택 단위 (v3.1)

시·군·구 하나씩, **시·도 전체**, **수도권 전체**, **전국** 중 아무 조합이나 담을 수 있다. 실제로는 "평택 아니면 안성", "경기 전체를 훑어보고 싶다"처럼 범위가 사람마다 다르다.

- 시·도 전체를 담으면 같은 시·도의 개별 시군구는 흡수한다(중복 제거).
- **전국**을 담으면 다른 선택을 모두 대체한다.
- 규제 판정: 전국·서울(전역)·경기 전체는 규제지역을 포함하므로 `규제`로 본다. 개별 시군구는 목록으로 판정한다.
- 결과의 검색 안내에는 "한 곳씩 나눠 검색하라"를 함께 표시한다. 법원경매정보는 소재지를 하나씩 넣는 편이 결과를 비교하기 좋다.

## 2. 물건 종류 · 면적 — 사용자 선택 그대로

v2는 출구 축에서 자동 결정했다. v3는 **사용자가 고른 것을 그대로 쓴다.**

| 종류 | 면적 선택지 | 기본값 | 근거 |
|---|---|---|---|
| 아파트 | 전용 59㎡ 이상 / 59~84㎡ / 84㎡ 초과 포함 | 59㎡ 이상 | 59㎡ 미만은 환금성 급감 |
| 빌라·다세대 | 방 3개 이상 / 방 2개 이상 | 방 3개 이상 | 빌라는 면적보다 **방 개수**가 환금성을 좌우 |
| 오피스텔 | 전용 30㎡ 이상 / 45㎡ 이상 | 30㎡ 이상 | 전용률이 낮아 공급면적 대비 실제가 작음 |

**모든 면적은 전용면적 기준**임을 화면에 명시한다. 아파트·빌라·오피스텔은 전용률이 크게 달라 공급면적으로 비교하면 오답이 된다.

**85㎡ 초과 + 매매사업자·법인 → 건물분 부가세 경고**(00_reg H-3). 국민주택규모를 넘으면 건물가액에 부가세가 붙어 실질 취득원가가 오른다.

### 2-1. 연식·규모·시설 — 검색창에 없는 조건 (v4.1)

법원경매정보 물건상세검색으로 거를 수 있는 것은 **지역·용도·최저매각가격·면적·특수조건**뿐이다. 아래 항목은 **검색 후 물건을 열어야** 확인할 수 있으므로, 입력은 받되 **"검색 후 걸러낼 조건"** 표로 따로 낸다.

| 종류 | 항목 | 선택지 | 확인처 |
|---|---|---|---|
| 공통 | **연식** | 상관없음 / 10년 이내 / 10~25년 / 25년 이상 | 건축물대장 **사용승인일** |
| 아파트 | **단지 규모** | 상관없음 / 300세대↑ / 500세대↑ / 1,000세대↑ | 네이버 부동산·KB시세 |
| 빌라 | **층수** | 상관없음 / 2~4층 / 1층·반지하 제외 / 1층 가능 | 매각물건명세서 + 현장 |
| 빌라 | **엘리베이터** | 상관없음 / 필수 | 건축물대장 · 현장 |
| 빌라 | **주차** | 상관없음 / 세대당 1대↑ / 가능하면 됨 | 건축물대장 주차대수 ÷ 세대수 |

**왜 이 항목들인가**

- **연식**: 수리비와 낙찰가가 여기서 갈린다. 신축은 손댈 게 없지만 경쟁이 붙고, 25년 이상은 싸지만 배관·창호 목돈이 나온다.
- **단지 규모**: 세대가 많을수록 같은 평형 거래가 잦아 **시세를 믿을 수 있고 팔 때 빠르다**. 300세대 미만은 시세 자체가 잘 안 잡힌다.
- **빌라 층수**: 1층·반지하는 침수·사생활로 되팔기 어렵고 탑층은 누수 위험이 있다.
- **빌라 엘리베이터**: 4층 이상인데 없으면 월세·매매가가 눈에 띄게 떨어진다.
- **빌라 주차**: 빌라는 주차가 곧 환금성이다.

결과 화면은 확인 순서를 하나로 묶어 제시한다: **① 매각물건명세서 → ② 건축물대장 → ③ 네이버·KB → ④ 현장.**

## 3. 특수조건 — 10개 항목을 사용자가 직접 고른다

v2는 권리 축(R)이면 자동으로 켰다. v3는 **법원경매 검색창의 특수조건 10종을 그대로 제시하고 사용자가 고른다.** 각 항목에는 **초보가 읽고 이해할 수 있는 한 문장 설명**을 붙인다 — 용어만 나열하면 고를 수 없다.

| 항목 | 설명 요지 | 난도 |
|---|---|---|
| 법정지상권 | 땅과 건물 주인이 갈려 건물주가 땅을 계속 쓸 권리. 땅만 낙찰받으면 건물을 못 치움 | 높음 |
| 별도등기 | 집합건물 대지권에 따로 걸린 등기. 근저당이 남으면 낙찰자가 떠안음 | 중간 |
| 유치권 | 공사대금 못 받은 사람이 건물을 붙잡고 버팀. 인정되면 낙찰자가 물어줌 | 높음 |
| 분묘기지권 | 남의 땅 무덤을 유지할 권리. 토지를 낙찰받아도 못 옮김 | 높음 |
| 특별매각조건 | 이 물건에만 붙은 조건. 보증금이 20~30%로 오름 | 중간 |
| 농지취득자격 | 농취증을 못 받으면 낙찰 취소·보증금 몰수 | 높음 |
| 선순위 임차인·전세권 | 말소기준보다 먼저 들어온 세입자. 남은 보증금을 낙찰자가 물어줌 | 높음 |
| 예고등기 | 소유권 소송 중 표시. 패소 시 소유권을 잃을 수 있음(제도는 폐지, 과거 등기 잔존) | 높음 |
| 우선매수신고 | 공유자 등이 같은 값에 먼저 사감. 최고가를 써도 뺏길 수 있음 | 중간 |
| 재매각 | 앞 낙찰자가 잔금 미납. 포기한 이유가 있고 보증금도 오름 | 중간 |

| 상황 | 처리 |
|---|---|
| 아무것도 선택 안 함 | 특수조건 미체크. 권리 단순한 물건만 |
| 하나 이상 선택 | 고른 항목만 검색조건에 표시 + 예비비 ×0.9 + "인수 금액 확정" 경고 |
| 초보 + 선택함 | 위에 더해 `danger` 배너 — "첫 3건은 추적만" |
| 초보 + 미선택인데 성향은 R | `warn` 배너 — "원하면 켤 수 있다" 안내 |

이유: 성향(R)이 곧 "특수물건을 검색하겠다"는 의사결정은 아니다. 취향과 실행은 분리한다. 또한 어떤 특수조건을 감당할 수 있는지는 사람마다 다르다 — 재매각은 보되 유치권은 피하는 것이 합리적일 수 있다.

## 4. 유찰 횟수 — 필터에서 **참고 지표**로 강등

유찰 1회당 최저가는 통상 20~30% 내려간다. 즉 **유찰 횟수와 가격 조건은 사실상 같은 정보**이며, 둘 다로 좁히면 볼 물건이 사라진다.

| 구간 | 읽는 법 |
|---|---|
| **1~3회** | 아파트에서 흔한 정상 구간 |
| **3회 초과** | 아파트에서 드묾. 가격이 아니라 **다른 이유**를 의심 — 권리 하자(선순위 임차인·유치권·지분), 물건 하자(누수·불법 증축), 과다 감정가 |
| **HUG 관련 물건** | 보증기관 대위변제 후 넘어온 물건은 유찰이 누적되는 경향. 전세사기·깡통전세 연관이 많아 임차인 관계를 특히 확인 |

화면에서는 성향에 따라 "1~3회"(안전·보유) 또는 "2~3회"(차익·모험)를 참고값으로 제시하되, **검색창에는 넣지 말라고 명시**한다.

## 5. 경매만의 제도적 우위 (결과에 항상 표시)

00_reg H-1 근거. 일반 매매와의 차이를 카드 3장으로 보여준다.

| 항목 | 일반 매매 | 경매 |
|---|---|---|
| 토지거래허가 | 필요 | **불요** |
| 토허 2년 실거주 의무 | 부과 | **면제** |
| 투기과열지구 조합원 지위 양도 | 재건축=조합설립 후, 재개발=관리처분 후 **제한** | **경·공매는 예외로 승계** |

세 번째가 특히 크다. 정비사업 구역 물건을 일반 매매로 사면 조합원이 될 수 없지만 경매로는 가능하다. 다만 **예외 해당 여부는 사건별로 갈리므로 입찰 전 조합·법무사 확인 필수**로 함께 안내한다.

## 6. 세금·규제 경고 (플래그)

| 조건 | 수준 | 내용 |
|---|---|---|
| 수도권 + 사업자·법인 | danger | 대출 사실상 불가 → 동원 자금이 곧 상한 |
| 85㎡ 초과 + 사업자·법인 | warn | 건물분 부가세를 원가에 반영 |
| 규제 + 1주택·다주택(개인) | danger | 추가구입 주담대 금지 |
| 규제 + 무주택(개인) | info | LTV 40%(생애최초 70%)·전입의무 / 토허 면제는 기회 / 고가낙찰은 함정 |
| 규제지역 포함 | info | 정비사업 조합원 지위 승계 가능(경매만) |
| 다주택 | warn | 취득세 8~12% — 단 **공시가격 기준 저가주택은 중과 제외** 규정이 있으니 공시가격부터 확인 |
| 다주택 + 차익형(개인) | warn | 단기 양도세 70/60% + 중과 |
| 사업자·법인 | info | 양도세가 아니라 사업소득·법인세. 건보료·부가세·장부 의무 |
| 빌라 선택 | info | 방 개수가 환금성. 전용면적으로 판단 |

**공시가격 저가주택 취득세 중과 제외**는 기준 금액·지역 구분이 확정 검증되지 않았으므로(00_reg H-2) 숫자를 단정하지 않고 "공시가격을 확인하라"는 행동 지침으로만 쓴다.

## 7. 시장 국면 브리핑 (미검증 표기 필수)

2026-08-02 세제개편(보유세 강화 + 양도세 2년 한시 완화)은 **사용자 제공 정보이며 원문 미확인**이다(00_reg H-5).

- 화면에 `미검증` 배지를 달고, "원문을 확인하라"를 빨간 글씨로 명시한다.
- 해석(보유 비용↑·처분 부담↓ → 완화 기간 내 회전에 유리)은 **전망이지 사실이 아님**을 함께 쓴다.
- 월세형에게는 "보유세 증가분을 수익률에서 먼저 빼라", 차익형에게는 "완화 기간 종료 시점이 매도 시점을 좌우한다"로 연결한다.

## 8. QA 체크

1. 골든 케이스 6건의 계산이 웹과 **원 단위까지** 일치하는가.
